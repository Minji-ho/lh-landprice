# CLAUDE.md — 광명시 개별공시지가 대시보드 (LH 현안 해결형 AI 교육 실습)

## 1. 프로젝트 개요
- LH 현안 해결형 AI 교육(2026-10-29) 실습 폴더. 광명시 개별공시지가 402필지(2025 → 2026)를 검증·설명하는 단일 파일 대시보드를 만든다.
- 환경: Windows 11 / PowerShell. **Python 미설치** — 스크립트가 필요하면 PowerShell 또는 브라우저 JS로 처리한다.
- 응답·UI·주석은 모두 한국어.

## 2. 파일 구조
| 파일 | 설명 |
|---|---|
| `4. 광명시_개별공시지가_실습용.csv` | 원천 데이터 (402필지, UTF-8) |
| `광명시_공시지가_대시보드.html` | 단일 파일 대시보드 (CSV 내장/로딩 포함) |
| 강의자료·워크북 PDF | 교육 참고자료 (읽기 전용) |
| 회의록 양식 `.docx` | 회의록 템플릿 (읽기 전용) |

- 다른 에이전트/사람이 HTML을 동시에 수정할 수 있다. **수정 전 최신 내용을 다시 읽고**, 요청 범위 밖 파일은 건드리지 않는다.

## 3. 데이터 사전
컬럼: 연번, PNU, 소재지, 법정동, 지번, 지목, 면적_㎡, 용도지역, 공시지가_2025, 공시지가_2026

- 규모: 8개 법정동, 9개 용도지역. 공시지가 단위는 원/㎡.
- 변동률 = (2026 − 2025) / 2025 × 100.

### 알려진 이상(오류 후보) — 모두 "후보"이며 확정은 담당자
| 유형 | 연번 |
|---|---|
| 2026값 자릿수 누락 | 69, 109, 267, 291 |
| 2026값 결측 | 247, 279 |
| PNU 중복 | 2쌍 (연번은 CSV에서 확인) |
| 지목 공란 | 379 |
| 급변 | 95 (+115%), 216 (+42%), 381 (-36%) |

- 급변 기준: 기존 코드 기준 유지 — **+30% 초과 또는 -10% 미만**. 담당자 확인 필요.

## 4. 대시보드 기획 요약
- **누가**: 지가 담당자(실무).
- **문제**: ① 오류 필지를 눈으로 찾음 ② 변동 이유를 설명하지 못함 ③ 동·용도별 비교가 번거로움.
- **원하는 변화**: **변동 사유 자동 설명**(핵심 기능). 이상 탐지·비교는 이를 뒷받침.
- **효과 기준**: 검증 소요 시간 감소.
- **원칙**: 변동 사유는 데이터로 *추정*만 가능. 추정 문구와 담당자 메모를 분리 표시.

## 5. 화면 구성
1. **상단 "확인 필요" 띠** — 이상 유형별 건수 요약, 클릭 시 큐로 이동.
2. **이상 필지 큐** — 유형(자릿수 누락/결측/PNU 중복/지목 공란/급변)별 목록, 확인 상태 표시.
3. **변동 사유 패널** — 선택 필지의 변동률·동/용도지역 평균 대비 위치·가능한 사유를 "추정" 라벨로 표시. 아래에 담당자 메모 입력란을 별도 영역으로 둔다.
4. **동×용도지역 히트맵** — 평균 변동률 또는 평균 지가, 셀 클릭 시 목록 필터.
5. **지도·목록** — 필지 목록(정렬·필터)과 지도(외부 타일 없이 가능한 방식 우선).

## 6. 개발 규칙
- **단일 HTML 파일** 유지. CSS/JS 인라인.
- **외부 의존 최소화** — CDN·외부 폰트·외부 API 지양(오프라인 교육장 가정). 필요 시 사전 협의.
- CSV는 **UTF-8**로 읽고 쓴다(BOM 유무 모두 처리). PowerShell에서는 `-Encoding UTF8` 명시.
- **한국어 UI**. 숫자는 천 단위 구분, 변동률은 소수 1자리 %.
- **추정과 사실 구분**: 원자료에서 계산한 값은 "사실", 사유 문구는 "추정(데이터 기반)"으로 시각적으로 구분. 담당자 메모는 사용자 입력이며 자동 문구와 섞지 않는다.
- 이상 필지는 삭제·보정하지 말고 표시만 한다. 원본 CSV는 수정 금지.
- 변경 후 브라우저에서 열어 콘솔 오류와 402필지 로딩을 확인한다.

## 7. 미결 사항
- PNU 중복 2쌍의 정확한 연번 정리.
- 급변 기준(+30% / -10%)의 업무적 타당성 — 담당자 확인.
- 변동 사유 추정에 쓸 근거 범위(동·용도 평균 대비, 면적, 지목 등)와 문구 표준.
- 담당자 메모의 저장 방식(브라우저 localStorage vs 내보내기).
- 지도 구현 방식(좌표 데이터 부재 시 대체 표현).
- 검증 소요 시간 측정 방법(교육 전·후 비교 절차).
